# Animated Foliage Banner

[English](README.md) | 简体中文

这个技能可以让 AI Agent 帮你制作带植物或毛发动态的 SVG 横幅。你可以给现有作品加上动画，也可以只描述一个想法，让 Agent 从头制作；已经做好的动画，也可以用它来检查。

它处理的是把画面做成动画时的具体工作：组装图层，让叶片和毛发摆动时根部留在原位，让相关的阴影、蒙版和裁切区域跟着一起变化。最后把所需素材打包进同一个 SVG 文件，就可以作为图片放进 GitHub README 等位置。

## 从现有作品或一个想法开始

现成的 SVG、普通图片、PSD，或一段需求描述，都可以作为起点。有 PSD 时，Agent 可以查看已有的图层和蒙版；只有普通图片时，需要先提取或重建要动的部分，脚本不会自动把任意图片分好层。没有素材也可以，Agent 能根据你的描述创作新场景。

画面长什么样，由你的参考和要求决定。你也可以把构图、配色等设计选择交给 Agent。这套技能提供制作方法，没有规定风格或构图。

## 怎么让 Agent 开始

把技能提供给 Agent，然后让它使用 `animated-foliage-banner`。说明横幅尺寸、展示位置、需要出现的文字，以及哪些部分要动。有参考图就一起提供；如果原作中有必须保留的细节，也请说明。

例如：

> 请用 animated-foliage-banner 做一张 1600×400 的 SVG 横幅，放在 GitHub README 里。标题是“Field Notes”，周围的植物持续摆动，文字保持不动。我没有现成素材，构图和配色由你设计。开启减少动态效果时，画面应保持静止。

制作时，Agent 可以截取动画某一时刻的画面、与参考图比较，也可以检查持续播放和减少动态效果的表现。这些检查能帮助发现问题，但好不好看、还原得怎么样，仍需看图判断。加载和播放性能也要在实际展示位置测试。
